QUẢN LÝ THƯ VIỆN BẰNG C++
1. Giới thiệu
Đồ án Tin học: Xây dựng chương trình quản lý thư viện bằng ngôn ngữ C++
2. Mục tiêu
* Quản lý thông tin sách và độc giả.
* Quản lý hoạt động mượn và trả sách.
* Thống kê và lập báo cáo.
* Áp dụng các cấu trúc dữ liệu theo yêu cầu đề bài.
* Lưu trữ dữ liệu bằng file.
3. Công nghệ
* Ngôn ngữ: C++
* Chuẩn dự kiến: C++11 trở lên
* Quản lý mã nguồn: Git và GitHub
* Lưu trữ: File nhị phân và file văn bản
4. Tiến độ thực hiện
* Tuần 1: Phân tích yêu cầu, xây dựng tài liệu SRS.
* Tuần 2: Thiết kế cấu trúc dữ liệu, module và luồng chương trình.
* Tuần 3–10: Tiếp tục triển khai, kiểm thử và hoàn thiện theo kế hoạch đồ án.
5. Tài liệu
* SRS: Tài liệu đặc tả yêu cầu.
* Design: Tài liệu thiết kế hệ thống.
6. Trạng thái
Đang thực hiện.
